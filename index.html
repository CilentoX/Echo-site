Perguntas frequentes

O Echo é gratuito?

Sim. O app é gratuito e o servidor roda na infraestrutura que você escolher — sem mensalidade, sem plano Pro.

Preciso de servidor próprio?

Para criar uma comunidade, sim — o Echo é self-hosted: uma VPS com Docker é suficiente. Para entrar numa comunidade, basta receber um convite e entrar com sua conta Google.

Como convido pessoas para minha comunidade?

Por convites gerados pelo próprio Echo. Quem entra escolhe o nome de usuário uma única vez — o resto é história.

Tem aplicativo para celular?

Ainda não. O foco atual é o desktop para Windows; macOS e Linux são os próximos da fila.

Tem chamadas de voz?

Está no roadmap — salas de voz nativas no app. A primeira versão foca no essencial de texto: canais, threads, reações e presença.

Onde ficam os meus dados?

No seu servidor. Mensagens e mídia ficam na sua infraestrutura — a única dependência externa é o login com Google.
